ZAWARUDO — Prototype 0.1.0
================================

Portable Windows build. No installation is required: run ZAWARUDO.exe.

The title menu is fully clickable and includes a brief HOW TO PLAY screen.

PLAYER 1
  Move: A / D        Jump: W        Let time run: S
  Aim: mouse         Charge/fire: hold/release left mouse button
  Toggle Super: T
  Confirm: Left Shift               Undo shot: R or right mouse button

PLAYER 2
  Move: Left / Right arrows         Jump: Up arrow
  Let time run: Down arrow           Aim: comma / period
  Charge/fire: hold/release Enter    Confirm: Right Shift
  Toggle Super: P
  Undo shot: Backspace

GAMEPAD
  Move: left stick / D-pad           Aim: right stick
  Jump: A                            Charge/fire: R2
  Toggle Super: Y
  Confirm: Start                     Undo: B or Select

GLOBAL
  M: mute        H: hide help        F10: next level        Esc: menu

First to three hits wins. Plan while time is frozen, confirm, and watch both
plans execute simultaneously. Knives remain in the arena between turns.
